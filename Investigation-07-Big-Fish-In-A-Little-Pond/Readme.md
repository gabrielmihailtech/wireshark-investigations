# Investigation 07 - Big Fish In A Little Pond

## Objective

Investigate malicious network activity within the BEPOSITIVE Active Directory environment, identify the compromised workstation and user account, and document associated indicators of compromise (IOCs).

---

## Executive Summary

Network traffic analysis identified a compromised Windows workstation within the BEPOSITIVE domain.

The infected host established encrypted communications with the domain `www.bellantonicioccolato.it`, which resolved to the external IP address `46.254.34.201`. Additional outbound communications were observed with `79.124.78.197`, where the host repeatedly sent HTTP POST requests to `/foots.php`.

The traffic pattern observed with `79.124.78.197` is consistent with command-and-control (C2) activity, including the transmission of binary data and repeated successful server responses.

The affected user account was identified as Andrew Fletcher.

## Findings

- Host 172.17.0.99 was identified as the compromised workstation.
- NBNS traffic identified the hostname DESKTOP-RNV09AT.
- Kerberos authentication traffic identified the user account afletcher.
- Additional packet analysis identified the full name Andrew Fletcher.
- TLS traffic revealed communications with www.bellantonicioccolato.it.
- The domain was associated with IP address 46.254.34.201.
- HTTP traffic to 79.124.78.197 contained repeated POST requests to /foots.php.
- The POST requests transmitted binary content and received successful responses.
- The observed behavior is consistent with malware command-and-control activity.

---

## Conclusion

The investigation identified workstation 172.17.0.99 (DESKTOP-RNV09AT) as the infected host within the BEPOSITIVE environment.

The compromised system, used by Andrew Fletcher (afletcher), communicated with external infrastructure including `www.bellantonicioccolato.it` (46.254.34.201) and `79.124.78.197`.

Repeated HTTP POST requests to `/foots.php` carrying binary data strongly suggest command-and-control activity.
The identified domains, IP addresses, and URLs should be treated as indicators of compromise and incorporated into detection, monitoring, and containment efforts.
